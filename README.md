# 🚀 NexusFlow Pro-Max

NexusFlow is an advanced, cyberpunk-themed device automation pipeline and NLP assistant.

## Features
- 🎤 **Voice & Text NLP**: Hinglish AI assistant ("Vani") support.
- 📲 **Deep ADB Integration**: Full Android device control over USB & WiFi.
- ✨ **Pro-Max UI**: Dynamic particle networks, HUD diagnostics, and glassmorphic toast notifications.

## Setup & Installation

1. Clone the repository and navigate to the folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   node server/index.js
   ```
4. Open  in your browser.
5. Connect your Android phone with **USB Debugging** enabled.

## Pro-Max Commands

Just trigger the Mic 🎙️ and say:
- "Vani, open Youtube"
- "Vani, flashlight on"
- "Vani, volume badhao"
- "Vani, take photo"

Enjoy controlling your phone without touching it!
